# BloomERA — portfolio starter

A responsive, single-page portfolio website built with plain HTML, CSS, and JavaScript.

## Included
- Modern, minimal visual direction
- Website development and social media content service sections
- Sweet Spice presented honestly as a self-initiated concept project
- Links to the existing Sweet Spice live demo and GitHub repository
- Responsive navigation for mobile screens
- Instagram contact CTA that stays unconfigured until you add your real profile URL
- Accessible skip link, labels, reduced-motion support, and semantic sections

## Run locally
Open `index.html` in your browser. No build tools or packages are required.

## Before publishing
1. Open `script.js`.
2. Replace the empty `INSTAGRAM_PROFILE_URL` value with your actual Instagram profile URL, for example `https://www.instagram.com/your-handle/`.
3. Review all copy and project details to make sure they accurately represent your work.
4. Test the page on a phone and desktop.
5. Deploy the folder to Vercel, Netlify, or GitHub Pages.

## Project integrity
Sweet Spice is labelled as a self-initiated concept/practice project, not paid client work. No client testimonials, performance claims, or contact details have been invented.

## Files
- `index.html` — page content and structure
- `styles.css` — visual design and responsive layout
- `script.js` — mobile navigation, year, and configurable Instagram link
